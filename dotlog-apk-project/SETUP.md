# Dotlog: build the Android APK (no Android Studio needed)

1. Create a free account at github.com and make a new repository (private is fine).
2. Upload everything in this folder to it, keeping the structure (including the hidden .github folder).
3. Open the repository, tap "Actions", choose "Build Dotlog APK", then "Run workflow".
4. After about 5 minutes, open the finished run and download the "Dotlog-APK" file at the bottom. Unzip it.
5. On your phone, open app-debug.apk and allow "install unknown apps" when asked.
6. Open Dotlog, go to Reminders, tap "Turn on", and allow notifications.

To change the app later, edit www/index.html and run the workflow again.
